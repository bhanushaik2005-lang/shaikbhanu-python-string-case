# Python String Uppercase and Lowercase

A simple Python program to convert a string into uppercase and lowercase.

## Author

**Shaik Bhanu**

## Repository Name

`shaikbhanu-python-string-case`

## File Name

`string_case.py`

## Description

This program accepts a string from the user and converts it into both uppercase and lowercase using Python string methods.

## Features

* Accepts a string from the user
* Converts the string to uppercase
* Converts the string to lowercase
* Simple and beginner-friendly

## Requirements

* Python 3.x

## How to Run

Run the program using:

```bash
python string_case.py
```

## Example

```text
Enter a string: Hello World
Uppercase: HELLO WORLD
Lowercase: hello world
```

## Algorithm

1. Read a string from the user.
2. Use the `upper()` method to convert it to uppercase.
3. Use the `lower()` method to convert it to lowercase.
4. Display both results.

## Time Complexity

**O(n)**

## Space Complexity

**O(n)**
